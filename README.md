# Aditya Kasthuri Portfolio

Graphic designer and automation specialist based in Chennai, India.

**Live site:** https://adityakasthuri55-svg.github.io

This repository hosts my portfolio website. It is a single static page (`index.html`) with no build step. The work is grouped into one folder per client, with a subfolder for each type of work.
